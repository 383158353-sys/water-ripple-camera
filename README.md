## 效果说明

用手指拨动摄像头画面，现实变成液态水面。  
GPU 物理模拟，真实波纹扩散，两种视觉风格可切换。

---

## 使用方法

1. 下载 `.html` 文件
2. **直接双击**，用浏览器打开
3. 允许摄像头权限
4. 把手伸进画面，开始拨动

> 建议用 Chrome / Edge，Safari 也支持

---

## 界面说明

| 按钮 | 功能 |
|------|------|
| LIQUID | 液态水波模式 |
| CRYSTAL | 晶体折射模式 |
| INTENSITY | 波纹强度 |
| RADIUS | 影响范围 |
| DECAY | 波纹消散速度 |
| SWITCH CAM | 前后镜头切换 |
| HIDE UI | 隐藏界面（点击任意处恢复）|
